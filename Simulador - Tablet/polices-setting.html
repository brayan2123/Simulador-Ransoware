Policy active

These controls determine how the simulated EDR responds when ransomware behavior is detected.

Detect ransomware behavior Generate an alert when suspicious encryption activity is detected.
Kill malicious process Automatically terminate the detected ransomware process.
Quarantine malicious file Automatically quarantine the malicious executable.
Automatic network isolation Isolate the affected endpoint when ransomware is confirmed.
Automatic rollback Restore modified files after the threat is contained.
Response mode Defines how much control remains with the analyst.
